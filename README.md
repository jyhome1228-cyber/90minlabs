# 90MIN LABS

## 공통 메뉴 · 주간 예측 기록 · 간결한 경기 리포트

2026-11-23 업데이트. 모든 페이지의 메뉴를 `assets/site-shell.js`와 `assets/site-shell.css`로 통일했습니다. 메뉴는 PREDICTIONS, MATCHES, LEAGUES, COLUMNS, MY PAGE, 칼럼 작성이며, HOME은 사용하지 않습니다. HTML에도 동일한 메뉴를 두어 첫 화면과 JavaScript 실행 후의 배치가 일치합니다.

### 마이페이지

`mypage.html`에서 한국시간 월요일부터 일요일까지의 주간을 선택하고, 경기별 홈 승리·무승부·원정 승리를 골라 이름을 붙인 묶음으로 저장합니다. 주간 이동, 대회 필터, 한글·영문 구단 검색, 선택 경기만 보기, 저장한 묶음 불러오기·수정·삭제, 주간별 기록과 적중 현황, CSV 내보내기를 제공합니다. 예정 경기 상세의 ‘승무패 기록하기’로 해당 경기가 있는 주간에 이동할 수 있습니다.

- 계정이나 서버 저장은 연결하지 않았습니다. 기록은 `90minlabs.predictionSets.v1` 키로 같은 브라우저의 localStorage에만 저장됩니다. 이 범위를 화면에 명시하며, 다른 기기와 동기화된다고 표현하지 않습니다.
- 경기 시작 전의 예정 경기만 새로 저장할 수 있습니다. 시작한 경기의 기존 선택은 수정하거나 제외할 수 없고, 아직 시작하지 않은 선택은 수정할 수 있습니다. 개인 묶음 전체 삭제는 명시적인 확인 후 가능합니다.
- `finished` 상태와 유효한 종료 스코어가 모두 있을 때만 실제 승무패를 비교합니다. 결과 미확인은 대기, 취소·연기는 집계 제외입니다. 일정이 사라지면 저장된 경기 정보를 유지하고 임의로 채점하지 않습니다.
- 저장 오류·손상된 기록·다른 창의 수정 충돌은 기존 데이터를 덮어쓰지 않습니다. CSV는 읽을 수 있는 기록 내보내기이며 계정 백업이나 자동 복원 기능은 아닙니다.

### 경기 리포트

기존의 긴 심층 해설을 최근 흐름 → 홈·원정 비교 → 조건부 경기 양상 → 예상 방향으로 이어지는 짧은 보고서로 정리했습니다. 충분한 기록이 있는 경기는 5–10문장, 보통 두 문단입니다. 자료가 적은 경우에는 설명 가능한 범위만 보여줍니다. 최근 5·10경기와 전체·해당 대회 선택이 보고서와 비교표에 함께 적용됩니다.

분석 기준·출처 설명 영역, 별도의 계산 방법과 확률 패널, 중복 요약과 긴 목차를 화면에서 제거했습니다. 비교표·최근 경기·맞대결·현재 순위는 유지합니다. 보고서의 예상 방향은 이전 성적과 장소별 기록이 같은 방향을 가리킬 때만 우세를 표시하며, 충돌하면 접전, 자료가 부족하면 판단 유보로 표시합니다. 확인되지 않은 선수 결장·전술 정보를 생성하지 않습니다. 종료 경기의 보고서는 ‘경기 전 흐름 리뷰’로 구분하며 최종 결과를 입력에서 제외합니다.

## 경기별 분석 페이지 · 2026-11-23

`match.html?id=…`는 모든 일정에 연결되는 경기 전용 화면입니다. 메뉴에서 HOME을 제거했으며 기본 진입 화면과 로고는 MATCHES로 연결됩니다. 이전 `#home` 주소도 경기 목록으로 연결됩니다.

- 경기 목록의 **경기 분석** 링크와 스코어에서 전용 페이지로 이동합니다. 돌아올 때 선택한 날짜, 대회, 하루·주간 보기, 경기 상태를 유지합니다.
- 핵심 분석, 최근 5·10경기와 전체·해당 대회 비교, 득실점, 무실점·양 팀 득점·합산 3골 이상 빈도, 홈·원정 기록, 이전 맞대결, 현재 순위와 출처를 제공합니다.
- PREDICTIONS는 현재 날짜부터 14일 범위에 저장된 예정 경기를 보여주며 같은 분석 페이지로 연결됩니다.
- 종료 경기에서도 대상 경기 결과를 최근 성적에 넣지 않습니다. 분석 기준은 대상 경기 시작과 현재 시각 중 이른 쪽입니다. 종료 경기의 분석은 현재 저장된 과거 기록을 재구성한 것으로, 당시 발행한 예측을 의미하지 않습니다.

### 분석 자료와 계산

`assets/match-analysis.js`는 브라우저와 Node에서 공유하는 독립 모듈입니다. `match-calendar.json`의 종료 기록과 표준 구단명을 우선 사용하고, `team-results.json`은 별칭과 대회, ±1일의 날짜를 대조해 중복 없이 보완합니다. 검증된 캘린더 스코어를 우선합니다. 시각 없는 보완 기록은 원문 날짜 다음 날의 KST 종료 시점까지 지난 경우에만 포함하며 화면에 **원문 날짜**로 구분합니다.

득점 기록 기반 참고 분포는 해당 대회에서 양 팀 각 5경기 이상, 홈팀의 홈 기록과 원정팀의 원정 기록 각 3경기 이상일 때만 계산합니다. 홈 득점 기준값은 `(홈팀 홈 평균 득점 + 원정팀 원정 평균 실점) / 2`, 원정 기준값은 반대로 계산하고 두 독립 포아송 분포를 조합합니다. 비교 화면의 대회 필터와 별개로 해당 경기의 대회 기록만 사용합니다. 선수 구성, 결장, 전술, 슈팅 기반 xG 또는 검증된 예측 확률이 아닙니다. 최근 5·10경기 선택은 모델의 장소별 표본 상한에도 적용됩니다.

현재 순위는 확인 시점을 표시하는 별도 스냅샷이며 사전 분석 계산에는 사용하지 않습니다. 외부 로고 조회가 실패해도 경기 분석은 로컬 JSON으로 작동합니다. 이번 변경은 화면과 계산 기능 개선이며 새로운 실시간 자료 수집이나 정기 업데이트를 추가하지 않습니다.

- `data/league-data.json`: 리그별 순위와 득점왕 자료. 리그별 마지막 확인 시각과 출처 포함

구단 역사에는 작성한 소개 또는 한국어 위키백과 요약을 사용합니다. 모든 구단의 역사 서술이 편집 검수까지 완료된 것은 아닙니다.

### 외부 데이터 소스

- 경기 기록: [open-matchday](https://github.com/oladeeayo/open-matchday), 정보 제공 및 비상업적 이용 목적, 출처 명시 필수. 원천 제공자의 이용 조건도 적용됩니다.

- 구단 로고 보완: [football-data.org](https://www.football-data.org). 로고 권리자는 각 구단이며 해당 서비스 사용 허가로 해석할 수 없습니다.
- 감독 자료: 프리미어리그 [공식 감독 명단](https://www.premierleague.com/en/news/4325264/list-of-202627-premier-league-club-managers), 그 외 [세리에 A](https://en.wikipedia.org/wiki/2026%E2%80%9327_Serie_A), [분데스리가](https://en.wikipedia.org/wiki/2026%E2%80%9327_Bundesliga), [리그앙](https://en.wikipedia.org/wiki/2026%E2%80%9327_Ligue_1)의 2026/27 시즌 명단. 감독은 2026-11-23 기준으로 기록되어 있으며 이후 인사 변경이 생길 수 있습니다.

경기 중단, 취소, 미확인 스코어는 결과로 판단하지 않습니다. `team-results.json`은 검증된 리그 경기 결과에 한정하며 컵대회, 유럽대항전, 친선경기는 포함하지 않습니다. 페이지는 동적 CSV를 불러올 수 있을 때만 최근 자료로 갱신하고, 실패하면 저장된 스냅샷을 유지합니다. 클럽 직원 및 선수단 명단의 정확성과 완전성을 보장하지 않습니다.

## 자료 업데이트

1. **순위/득점왕:** `data/league-data.json`을 수정합니다. 구단명은 `team-profiles.json`의 `name`과 동일하게 유지하고, `updatedAt`과 `sourceUrl`을 함께 갱신합니다.
2. **감독/경기장:** `data/team-profiles.json`의 `manager`, `managerVerifiedAt`, `managerSourceUrl`, `stadium`을 검토해 갱신합니다.
3. **최근 리그 경기:** `open-matchday` 자료가 갱신되면 팀 페이지에서 최신 CSV를 불러오도록 되어 있으나, 서비스 중단과 CDN 캐시에 대비해 `data/team-results.json`의 백업도 주기적으로 갱신합니다.
4. **팀 추가:** `team-profiles.json`과 `team-results.json`에 동일한 `league:teamName` 키를 추가하고, `league-data.json`에 동일 팀 이름으로 등록합니다.
5. **최근 소식:** 현재는 구단 공식 사이트와 뉴스 검색 링크를 제공합니다. 기사 목록 자동 게시·검수 기능은 추후 개발 대상입니다.

## MATCHES 페이지

`index.html#matches`는 현재 2026/27 시즌 경기 일정 및 종료 결과 페이지로 연결됩니다.

- 7개 대회 선택: 프리미어리그, 잉글랜드 챔피언십(2부), 라리가, 세리에 A, 분데스리가, 리그앙, UEFA 챔피언스리그
- 한국시간 기준 현재 날짜와 오늘의 경기 기본 표시
- 날짜 선택기, 이전 날·다음 날, 오늘 경기 버튼, 하루·주간 모드 전환
- 전체, 예정, 종료, 결과 미확인 상태 필터
- 구단 로고와 구단 프로필 링크
- 펼쳐보기: 두 팀의 직전 리그 5경기 승무패와 자료 출처
- 종료된 경기는 최종 스코어 표시, 확인되지 않은 경기는 점수 미표시

파일:
- `assets/matches.css`: 반응형 경기 목록 스타일. 흑백 UI에 구단 엠블럼만 원색.
- `assets/matches.js`: 경기 목록과 대회·상태·날짜 전환.
- `data/match-calendar.json`: 2026-11-23 기준 2026/27 시즌 공개 경기 일정·결과 스냅샷(잉글랜드 챔피언십 포함).

일정 및 종료 스코어는 비상업적 이용 조건의 [open-matchday](https://github.com/oladeeayo/open-matchday)를 근거로 작성했습니다. 소스는 주기적으로 바뀌지만 `data/match-calendar.json`은 현재 자동 갱신되지 않습니다. 최신 데이터 갱신과 공식 일정 대조를 운영 과제로 남깁니다. 경기 중 실시간 스코어나 확정되지 않은 경기 결과는 제공하지 않습니다.

추후 경기 예측 리포트를 발행할 때는 경기의 고유 ID와 예측 보고서를 연결하여, 해당 경기에서만 "경기 전망 보기" 링크를 활성화하는 것을 권장합니다.

추가로 잉글랜드에서는 2부 **EFL Championship**까지 경기 일정을 제공하며, League One 이하의 하위 리그는 제공하지 않습니다. 리그 순위와 구단 상세페이지는 현재 기존 4대 리그 기준이며, 챔피언십 팀 상세 정보는 별도 확장 대상입니다.

## 현재 날짜 및 경기 자료 확인

MATCHES는 방문 시 한국시간(Asia/Seoul)의 **오늘 날짜**를 기본 선택하고, 헤더 영역에 날짜와 현재 시각을 표시합니다. 페이지가 열린 동안 시각을 30초마다 다시 확인하며 날짜가 바뀌면 오늘 경기 선택도 업데이트합니다. 달력에서는 하루/주간 보기와 날짜 직접 선택이 가능합니다.

2026년 11월 23일 오전 11시 56분(한국시간)에 open-matchday의 7개 대회 CSV와 저장된 스냅샷의 경기 수 및 종료 스코어를 대조했습니다. 확인된 종료 기록 802경기(라리가, 챔피언십 포함)의 스코어 불일치는 없었습니다. 이 확인 시각은 `data/match-calendar.json`의 `verifiedAtKst`에 저장되며, 화면의 현재 시각과 별도로 표시합니다.

**중요:** 이 검증은 실시간 데이터 수집이 아니라 그 시각의 공개 소스 대조입니다. 소스가 결과를 아직 제공하지 않은 경기는 '결과 확인 필요'로 표시하고, 진행 중 스코어를 추정해 보여주지 않습니다. 자료는 자동으로 다시 수집되지 않으므로 이후 최신 결과 갱신은 추가로 설정해야 합니다.

## 2026/27 UEFA 리그 페이즈 순위

`leagues.html?league=ucl`, `leagues.html?league=uel`, `leagues.html?league=uecl`에서 UEFA 공식 리그 페이즈 잠정 순위를 제공합니다.

- 챔피언스리그 UCL: 36개 팀, 4경기 종료 기준
- 유로파리그 UEL: 36개 팀, 4경기 종료 기준
- 컨퍼런스리그 UECL: 36개 팀, 3경기 종료 기준
- `data/uefa-standings.json`: UEFA 공식 순위표 기록을 날짜와 출처 URL과 함께 저장. 2026년 11월 23일 기준.
- 구단명과 컬러 엠블럼을 함께 표시. 지원되는 프로필은 클릭하면 구단 상세페이지로 연결합니다.
- 1~8위 16강 직행권, 9~24위 플레이오프권, 25~36위 탈락권을 모노톤으로 구분합니다. **진출 및 탈락은 아직 확정되지 않았습니다.**
- `data/team-profiles.json` 내 `uefaCompetitions`: 3개 대회 각각 36개 참가팀 링크를 유지. 이미 국내 리그 페이지가 있는 팀은 기존 프로필을 재사용합니다.
- `data/team-results.json`: 신규 유로파 및 컨퍼런스 구단의 리그 페이즈 경기를 별도 기록.
- `data/match-calendar.json`: 유로파 및 컨퍼런스리그 경기 일정과 최종 결과를 추가하여 9개 대회 2,700개 경기를 제공합니다.

2026년 11월 23일에 [UEFA UCL](https://www.uefa.com/uefachampionsleague/standings/), [UEFA UEL](https://www.uefa.com/uefaeuropaleague/standings/), [UEFA UECL](https://www.uefa.com/uefaconferenceleague/standings/)의 108개 참가팀 기록을 각 대회 공개 경기 결과에 대조했고, 승무패·득실점·승점에 불일치를 발견하지 못했습니다. 순위는 공식 순서에 따르며 동률일 때 일반적인 골득실차만으로 정렬하지 않습니다.

사이트는 독립적인 비상업적 정보 서비스입니다. 공식 인증이나 리그·구단의 후원을 뜻하지 않습니다. 로고의 권리는 원권리자에게 있으며, 외부 제공처에서 이미지를 찾지 못하면 약칭으로 대체합니다. 데이터는 자동 갱신되지 않고 마지막 저장본을 사용합니다.
